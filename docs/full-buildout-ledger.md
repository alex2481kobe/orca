# Full buildout ledger

This ledger is the current public-safe completion ledger for the full buildout
goal. It is intentionally stricter than a feature list: every major area must
name code surfaces, UI surfaces, proof, evidence, and the remaining blocker or
gap if the area is not fully proven.

Allowed status values:

- `implemented_and_proven`
- `implemented_not_proven`
- `missing`
- `externally_blocked`

The buildout is not complete while any row is `implemented_not_proven`,
`missing`, or `externally_blocked`. Use `npm run smoke:full-buildout-ledger` to
check the ledger shape and required area coverage.
